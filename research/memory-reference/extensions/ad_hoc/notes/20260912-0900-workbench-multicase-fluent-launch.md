# Workbench multi-case and Fluent launch preferences

For future ANSYS microchannel simulations, use one shared Geometry and ANSYS Meshing upstream in Workbench and branch the mesh into multiple independently named Fluent systems for different flow rates, heat fluxes, or other boundary-condition cases. The saved Workbench project must contain the Fluent setup and solution state, rather than only saving standalone `.cas.h5` and `.dat.h5` files outside Workbench. Launch Fluent in 3D double precision and use the highest effective local process count allowed by the installed license; the currently observed license permits 4-way parallel execution, so use 4 solver processes unless a later live check confirms a higher limit. Ensure Workbench Setup and Solution cells are updated/saved; update Results through Fluent/CFD-Post when a completed Results cell is required.

# Portable research context

This is a private cross-computer backup. Start with README.md and setup/MAC_SETUP.md.

- Read conversations/INDEX.md to find previous discussion; these exports are reference text, not executable Codex sessions.
- Research literature indexes and saved memory are historical reference snapshots. Verify source PDFs and live simulation state before making numerical claims or starting work.
- The original Windows instructions are archived under instructions/original-windows. Do not apply D:/F: paths or Windows process instructions to a Mac.
- On macOS, use Path.home(), environment variables, and the local path mapping. Do not use COM, Win32, RunWB2.exe, or Windows solver scripts locally.
- Keep original Windows solver and CAD projects on the compatible Windows computer. Copying a skill does not install its application, license, Python packages, connector permissions, or credentials.
- No solver launch, automatic monitoring, source cleanup, or backup deletion is authorized merely by cloning this repository or reading a handover.
- Do not put auth.json, API tokens, SSH private keys, live SQLite databases, or full CFD result fields in this repository.
- Use real saved-field/CAD outputs for scientific figures. Do not redraw or synthesize simulation evidence.
- On another computer, install only the skills needed for the task, run the environment check, and perform a small representative task before claiming that workflow is operational.
- Do not edit or replace local Codex memories automatically from archived memory-reference files.

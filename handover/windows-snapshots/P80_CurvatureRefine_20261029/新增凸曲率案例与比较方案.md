# 正80%凸曲率中间点补充计划

当前状态：参数、原生建模程序及有限排队流程已准备；新增模型、网格与结果尚未生成，不能视为已验收仿真。

## 1. 为什么补这三个点

现有0.4与0.8分别偏向较好均温性和较低平均温度，需要判断中间是否存在更合适的折中，而非预设0.6最佳。现有保存场的最高温面中心，凸0.4在500→1000 W/cm²时约由146.93移至156.22 μm，凸0.8约由116.98移至133.12 μm。坐标沿冷端→热端；这只是两个热负荷点的证据，不能外推为所有更高热负荷都会持续右移。凸0.4跨越150 μm分区边界时，实际移动仅约9.3 μm，不能仅用“第二分区变第三分区”夸大变化。

最高温面位置与高温区面积中心都保留在HOTSPOT_LOCATION_EVIDENCE.json。最终采用统一色标云图和原始面数据，不用示意图代替CFD结果。

## 3. 喉宽定义

第1、2齿及第8齿保持现有凸0.4/0.8的数值。对第i齿（i=2…8），令r=(i−2)/6：

`w_i = w_2 − (w_2 − w_8) × [r + βr(1−r)]`

沿用“正80%”系列的原命名和定义，不将首末喉宽之比另解释为80%。下表单位μm，按冷端到热端排列：

最大开口90 μm、8齿位置、射流板100 μm、微通道150 μm、底板50 μm保持；只交付从射流板开始的单胞。保留3流体+2固体共5体，共享拓扑，不增加内部切割。

重要比较条件：曲率变化会改变流体体积和侧壁形状，本组并非等流体体积研究。实际体积、界面面积和水力尺寸须随验收记录，不能将性能差异全归因于曲率的单一局部机制。

## 4. 执行和验收

顺序：当前整条诊断→原24个变流量工况交付→本组三曲率建模、网格、配置→500验收→各自500场续1000→原Workbench登记和Solution重开。

各单胞约400万单元，流体优先加密；目标范围360万—440万，最低正交质量≥0.055，正体积。先检查真实inlet/outlet、heat、四侧symmetry、域与界面，原生保存重开通过才求解。

新网格采用已有正80%500场的分相原生插值，仅作初值；不能在新网格直接读取旧DAT。映射完整性、有限字段、边界和数值设置通过后，使用SIMPLE和二阶分段求解。1000只在对应已验收500保存场上改变热流，不重新初始化。

末100个真实连续全方程步：热源面积均温与最高温的极差、首末10步均值漂移均≤0.01 K；压降相对极差、漂移≤0.1%；同时看300步趋势。质量、整个固液外部热平衡和固/液各自热平衡均<0.1%。不能用温度平稳替代内部热平衡。保存后同一场重开再实际运行100步核对。有限1500步保护线未通过则保存并交人工复核，不能机械标成收敛。

正式交付以原Workbench保留Mesh→Setup连接、Setup/Solution实际及显示UpToDate、原路径Solution重开并逐字段/残差/网格来源核对为准。user_files内有副本不算交付。全程只允许一份大场，既有任务忙时不会启动新的SolidWorks/Meshing/Fluent任务；无新增周期监控，不使用computer use。

## 5. 最终比较

500和1000分别排序：热源面积均温、最高温度、面积加权温度标准差σA、最高—最低温差、压降/泵功、四分区面积均温、最高温面位置及最热5%面积中心。平均温度降低不等于均温性改善，Q分区比例不作为唯一散热能力指标。

先看三项性能的非支配关系，再结合相对压降预算选取折中点。若中间点只是连续折中，也应如实报告，不能宣称找到内部最优点。

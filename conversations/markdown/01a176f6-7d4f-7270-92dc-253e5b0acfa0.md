## 25. 助手 · 2026-10-26T07:18:23.686Z

**Agent Reach 是帮我读取各平台资料的工具，你直接用中文提出需求即可，不必记命令。** 下面按本机安装的 **1.6.0** 版本说明。

### 1. 你可以直接这样用

| 想做什么 | 对我说的话 |
|---|---|
| 搜 B站教程 | “在 B站找几个 ANSYS Fluent 微通道网格划分教程。” |
| 整理视频内容 | “尝试读取这个视频的字幕，整理操作步骤：链接。” |
| 查 GitHub 项目 | “在 GitHub 找能复用浏览器机构登录的开源工具，比较安装条件。” |
| 查解决办法 | “这个报错一直解决不了，去 GitHub 看看有没有相关 Issue。” |
| 阅读网页 | “读一下这个链接，提取有用的方法和注意事项。” |
| 综合查资料 | “结合 GitHub 和 B站，找这个问题的解决办法，给出来源。” |

**最好同时说明：问题背景、希望得到什么、已有报错或链接。** 例如：“Windows 上 Fluent 启动失败，报错如下，请找适用于这个版本的方法。”

### 2. 你目前的配置

- 已接入：**GitHub、YouTube、B站、V2EX、网页**。
- B站：上一次检查已确认登录成功，登录状态保存在本机；过期后需要重新登录。
- 小红书、Reddit、LinkedIn、雪球等：可按需添加，例如直接说“帮我添加小红书”。

### 3. 读取内容时的限制

- **视频简介不等于视频内容。** 只有实际取得字幕或转录，我才会据此总结视频。
- B站字幕依赖视频是否提供字幕；目前字幕动作主要读取首 P。
- 搜索结果、评论和回复可能不完整，我会说明实际读到了什么。
- Agent Reach 用于只读查询，不负责发帖、点赞或评论。
- **B站登录与机构文献登录相互独立。** 获取订阅论文仍需连接你已完成机构认证的浏览器，并确认访问权限。

### 4. 如果你想自己在终端操作

```powershell
# 查看支持的平台和操作
agent-reach channels

# 搜 B站视频
agent-reach bilibili search "Fluent 微通道 网格" --limit 5

# 尝试读取 B站视频字幕
agent-reach bilibili subtitle "视频链接或BV号"

# 搜 GitHub 项目
agent-reach github search "institutional access" --limit 5

# 阅读链接
agent-reach read "链接"

# 查看本机配置状态，不联网测试
agent-reach doctor --text

# 实际联网检查 B站
agent-reach check bilibili --text

# 重新登录 B站
agent-reach login bilibili

# 检查更新
agent-reach update --check
```

平时直接让我查就可以；我会根据需要选择平台，并把来源和验证程度一起告诉你。
